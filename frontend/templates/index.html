      Firewall
      
              
      Per-interface iptables rules — every interface gets its own rule set, like a security group. Off by default.
      
            
      
            
          
      

          
      Running in simulation mode — no real iptables commands are executed; the commands that would run are shown in each action's steps log.
      

          
          
      
            
      
              
      
                
      Firewall enforcement
      
                
      Master switch. Off (default) — no iptables rules are installed, no matter what's configured below. On — every interface marked "enforce" gets its chain installed. Established connections and this dashboard's own port are always allowed first, so a bad rule can't lock you out of Splitter itself.
